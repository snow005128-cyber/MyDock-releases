# Snow Dock 1.6.2

这是 Snow Dock（原名 MyDock）的发布分支，软件内「检查更新」从这里下载新版本。

- 第一次安装：下载 [SnowDock.exe](https://github.com/snow005128-cyber/MyDock-releases/raw/dist/SnowDock.exe)，放进一个固定的文件夹（例如 `D:\软件\SnowDock\`）后双击运行。
- 之后在 Snow Dock 的「设置 → 通用 → 检查更新」里一键更新。

## 这个版本更新了什么

· 新增：按快捷键叫出 Dock 后，会保持显示一段时间再收回（默认 3 秒）。时长可以在「设置 → 隐藏 → 快捷键 → 按快捷键后显示多久」里调，1–60 秒，可拖滑块也可直接输入。
